# 13주차 데이터 과학과 4차 산업혁명

## 핵심 주제
Data Science, Big Data, IoT, AI, 응용분야, 데이터 보안을 학습한다.

## 학습 목표
- 데이터 과학의 정의와 중요성을 설명한다.
- 데이터, 정보, 지식의 차이를 구분한다.
- 4차 산업혁명의 핵심 요소를 데이터 관점에서 이해한다.
- 빅데이터의 개념과 등장 배경을 설명한다.
- AI, IoT, 헬스케어 등 응용 사례를 연결한다.
- 데이터 보안 요구사항을 사례와 함께 설명한다.

## 수업 활동
- 데이터 과학자 역할 토론
- 빅데이터와 IoT 사례 연결
- 데이터 보안 위험과 보호 방법 정리
